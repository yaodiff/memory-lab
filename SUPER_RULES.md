# Super rules

1. Change this file only after the repository owner explicitly approves the proposed change in a GitHub issue.
2. Keep internal system names, colleagues’ names or identifying details, internal links, raw data, and internal examples out of the repository, including issues, pull requests, and commit messages.
3. Report internal figures only as ratios or coarse estimates. Label them as coming from a small internal sample.
4. Use exactly one of **Works**, **Does not work**, or **Inconclusive** for each experiment’s conclusion. Report negative results as observed.
