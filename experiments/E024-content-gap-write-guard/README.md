# E024 发现缺内容并在增量写入时防回退

- 结论：**Works**（小样本离线试点能让补写页进入前五，提交前校验覆盖了已知回退路径）
- 日期：2026-11-25
- Issue：[#89](https://github.com/yaodiff/memory-lab/issues/89)
- 来源：自有场景小样本，含只读搜索观察、冻结回放和受控写入验证
- 交接：无

## 发现与复验

从两周的搜索样本中按会话去重，聚合反复出现、能回到权威材料的需求，再人工区分已有但排得低、确实缺页，以及应现场查证的问题。聚合出的候选缺口涉及 127 个会话的 269 次搜索，其中约三分之二未观察到可归因的采纳。该信号只用来筛选，缺页仍需逐项核查。选出 5 类缺口，各起草 1 页。起草前按会话冻结每类 3 个不同问法，草案生成只接收缺口与来源，留出问法留给评测。相邻意图另设 4 条对照。

两臂共享历史实际返回页和冻结原语料。实验臂只把草案加入 BM25，再与历史结果按 RRF 融合。目标页进入前五 **14/15**，首位 **0/15**，相邻意图对照前五顺序 **4/4** 不变。试点没有对应的排序前全量候选，衡量的是冻结条件下新增页的可达性。答对率、真实采纳及搜索线上效果未测。

## 增量防回退

一次性整理后，对照同页不同版本，确认旧写入 Worker 仍可能把已合规摘要改回旧格式。在同一批 331 张新页的离线回放中，摘要格式通过率从约 5% 升到 100%。原来约一半的新页挂在宽泛父实体上，试点规则对新页不新增父挂载。找不到可信叶实体或独立实体时留空，既有页更新保留原挂载。

把校验放在创建和更新的提交前路径。标题或正文变化时重新计算摘要，新增或改写的类型化关系必须能回溯到对应来源，缺可靠来源的关系行拒写。受控写入覆盖了新页挂载、摘要重算、有效出处和拒绝无效出处。冻结回放只重放了部分写入阶段，长期自然流量的合规率还未量化。

## 结论

补页先回源、隔离留出问法，再人工审核。判断增量链路有没有把旧格式带回来，要在提交前覆盖相关写入入口，并用版本读回核对。一轮存量修补的通过率只能说明修补当时的状态。
