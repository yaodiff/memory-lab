# E021 150 题留出集比较 BM25 融合与四路召回

- 结论：**Works**（在这批留出题上，保留生产排序并加入 BM25 融合提高了前五证据找齐率）
- 日期：2026-11-25
- Issue：[#89](https://github.com/yaodiff/memory-lab/issues/89)
- 来源：自有场景小样本。四路回放参考 [Hindsight 召回说明](https://hindsight.vectorize.io/developer/retrieval)和[对应公开版本](https://github.com/vectorize-io/hindsight/commit/550ef5e30462)
- 交接：无

## 假设与做法

在生产向量候选之外加入独立的 BM25 排名，可能补回语义检索漏掉的页。对照组保留生产排序。实验组用倒数排名融合（RRF）合并生产候选与词法候选。另外在相同页面快照上搭建语义、词法、图和时间四路的页面级适配，并对比有无交叉编码器（CE）。分别在保留和移除冗余父挂载的快照上回放这两臂。适配使用页面与本地索引，缺少上游事实级边和原生写入链路。

扩展留出共 150 题，含已冻结的早期 60 题。60 道多页题是抽样配额。两次独立标注对本轮排名和采纳反馈保持盲态，分歧交第三次处理。状态和完整证据集初标严格一致 112/150。144 道可计分题包括 84 道单页题和 60 道多页题。另 6 道弃标题完成回放，从效果分母剔除。前五覆盖至少一整组必需证据才算找齐。

## 数据

| 排序 | 全部可计分题 | 多页题 |
| --- | --- | --- |
| 生产基线 | 86/144 | 19/60 |
| 生产候选 + BM25，经 RRF 融合 | 107/144 | 30/60 |
| 四路融合 + CE，移除冗余父挂载前后 | 54/144 → 54/144 | 9/60 → 9/60 |
| 四路纯 RRF，移除冗余父挂载前后 | 53/144 → 54/144 | 6/60 → 7/60 |

生产候选加 BM25 比生产基线高 **14.6 个百分点**，配对 95% CI **[+8.7, +20.8]**。区间按会话聚类做 10,000 次 bootstrap。每组对比的两臂使用相同的重采样权重。

## 结论

保留生产排序再融合词法候选，在扩展留出中收益最大，四路页面适配无论带不带交叉编码器都低于生产基线。剪掉冗余父挂载也没有改变带交叉编码器的找齐率。此前 Timeline 记录的是不同样本上的探索性回放。

## 没覆盖的

各臂的候选生成和索引不同，四路适配的差距无法单独归因给图、时间或交叉编码器，也无法外推到原生 Hindsight。历史题用了冻结时的索引，原查询当时的权限与索引版本没有完整保留。这里量的是证据页排名，实际请求延迟、Agent 采纳和默认启用仍需另测。此前的 60 题与扩展集重叠，不能当作独立复现。
