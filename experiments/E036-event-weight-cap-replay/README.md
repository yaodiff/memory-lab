# E036 放宽事件页降权和结果上限

- 结论：**Does not work**
- 日期：2026-11-27
- Issue：[#99](https://github.com/yaodiff/memory-lab/issues/99)
- 结果（内部小样本）：离线仅放宽上限时，原权重下效果持平。减轻降权所得找齐率增益不显著，较激进的变体使前五误入的一次性非金标事件槽位变为约 3–15 倍，挤掉可复用记忆。保留原护栏。
- 局限：本轮降权实验围绕全局调权。冷藏后按问法意图抬权仍无增益，按事件页质量抬权仅保留为离线影子候选，见 [E050](../E050-targeted-event-boost-after-cooling/README.md)。
