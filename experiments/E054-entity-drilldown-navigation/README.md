# E054 实体下钻导航

- 结论：**Inconclusive**
- 日期：2026-11-29
- Issue：[#101](https://github.com/yaodiff/memory-lab/issues/101)
- 方法：以同一轮实返前五为起点，用线上读回的页面离线回放直接挂载一跳和带出处关系二跳，按额外读页预算比较整组找齐。另对照固定子叶与关键页目录。
