# E### 标题（一句话说测什么）

- 结论：行 | 不行 | 说不清（选一项）
- 日期：开始 YYYY-MM-DD / 结束 YYYY-MM-DD
- Issue / PR：#N / #M
- 来源：自己的想法 | 业界论文（链接） | 产品指标回顾 YYYY-WW（公开摘要）
- 交接：无 | `handoff/H-E###.md`

## 假设

在 X 条件下，做 Y 会让 Z 变化至少多少？

## 做法

链接公开或合成数据集。记录实验组、模型请求名与实际解析名、命令原文和运行所用的提交。把可公开的固定参数写入 `config.json`。

在运行前写明判定线，说明什么结果记「行」、什么结果记「不行」。其余记「说不清」。

## 数据

用表格摘要公开结果，有可公开的 `results.json` 时附链接。写明样本量、判官一致率及分母、未跑完的 case，以及按预先规则剔除的 case 和原因。

## 结论

写明判定和值得保留的证据，以及对相关实验或文章的影响。

## 没覆盖的

记录未测到的边界、可能影响结果的因素，以及证据能支持的范围。
