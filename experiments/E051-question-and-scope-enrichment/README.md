# E051 已有页补问法和适用范围

- 结论：**Works**
- 日期：2026-11-29
- Issue：[#101](https://github.com/yaodiff/memory-lab/issues/101)
- 问题：在保持向量、金标及排名配置相同的条件下，只给原页补有出处的问法和适用范围，是否改善前五整组找齐。
- 方法：基于既有失败题拟补丁。对比原语料、仅补已有页、仅加离架草稿和二者合用。离线重建词法索引，固定向量、融合权重、五槽预算和事件上限。同题成对计分，留出题以来源会话为簇做 bootstrap；另检查独立金标的证据页位、整组和首位，以及错页槽位。
- 结果（内部小样本）：较新在架快照中，仅补已有页的前五整组找齐约 +4.9 个百分点，配对 95% 区间 +1.5 至 +8.6，未观察到整题退步。在仅使用同版正文的快照敏感性切片，约 +2.8 个百分点（+0.7 至 +5.8）。固定金标和错页率持平；离架草稿单独加入的整题差值为 0。部分提升依赖语料版本。
- 边界：Works 只覆盖这次离线回放。补丁来自该批失败题，区间描述这个回放的抽样不确定性。独立金标未观察到收益，推广前应用预先冻结的新留出题复验；本实验未测线上采纳。此前 [E038](../E038-targeted-content-repair/README.md) 的线上数据与排序切换重叠，两个结果各自保留。
