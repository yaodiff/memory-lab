# E052 定点补问法和适用范围线上复测

- 结论：**Works**
- 日期：2026-11-29
- Issue：[#101](https://github.com/yaodiff/memory-lab/issues/101)
- 方法：按真实漏题回源核查。以原页补问法、适用范围为主，确有证据缺口时新建。分批写入、核对正文摘要与索引，前后用同一组请求和冻结必找页评分。
- 结果（内部小样本）：首轮生产写后读回一致率 100%。有冻结必找页的留出题，前五整组找齐约 +5.6 个百分点，整题退步率 0%。大多数新增找齐题与本批写入页对应，另有增益与本批页面无交集。
- 第二轮（离线）：同一配置固定既有向量，仅改变文本；含旧正文的回放前五整组找齐约 +1.4 个百分点（配对 95% 区间 0 至 +3.6），同版正文约 +0.7 个百分点，原已找齐题未回落。第二轮尚无线上验证。
- 边界：首轮实测覆盖从这批漏题产生的补丁，生产前后对照也有同期变化。推广需用新留出、独立金标和错页复核。采纳另行验证。 [先前离线 E051](../E051-question-and-scope-enrichment/README.md) · [批量增补 E056](../E056-blind-faq-enrichment/README.md)
