# E045 实体结构进入主榜的四种方法

- Issue：[#99](https://github.com/yaodiff/memory-lab/issues/99)
- 结果（内部小样本）：离线比较叶名扩候选、同叶提权、导航降权加行动页提权、带出处关系一跳扩展。四法均未过影子门槛。最好方案的留出前五找齐仅 +0.7 个百分点，区间触零，且固定金标首位下降约 2.9 个百分点。不开影子。
