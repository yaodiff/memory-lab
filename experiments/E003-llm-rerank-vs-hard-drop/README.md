# E003 相关性判别模型的硬剔除与两段式重排

- 结论：Does not work
- 日期：2026-11-19 至 2026-11-21
- 议题：[原实验 #16](https://github.com/yaodiff/memory-lab/issues/16) · [更正 #80](https://github.com/yaodiff/memory-lab/issues/80)

11 月 21 日的[三题集复验](../E015-two-stage-rerank-replay/README.md)取代早期小样本的上线判断。三个题集的正确页首位命中率均下降。前 3 小幅改善或持平，前 10 持平。停止推进这套重排上线。

## 假设与做法

用逐条判断的相关性分数（pointwise）硬剔除低分候选，或先把弱相关候选移出组内比较，再让模型比较保留候选的相对相关性（listwise）。另比较严格的「能直接回答」与宽松的「对象和动作对口，线索也可用」。硬剔除预设门槛为错页拦截至少 80%、正确页误删至多 3%，且空结果率不增加。

## 早期离线结果

以下读数为小样本汇总比例。

- 严格口径硬剔除约拦截 80% 的错页，但正确页误删约 14%，约 9% 的题变成空结果。测试的阈值范围内未找到同时满足拦截和误删约束的阈值。
- 宽松口径在该批候选上把正确页误删率降到 0%，约拦截 75% 的错页。只提供入口或线索的页面会受严格口径误伤。
- Listwise 分数随组内候选数变化。将组内概率直接作为剔除阈值，正确页误删率约 20%–32%。
- 早期多空间小样本中，两段式重排把正确页前 3 命中率从约 82% 提到约 87%，首位从约 69% 降到约 67%，前 10 约 91% 持平。针对同一批候选调出的首位保护把首位和前 3 提到约 73% 和 89%。这是样本内调参，11 月 21 日复测时，同题的逐条判断分数漂移曾导致保护失效。

## 预发探针与边界

重复请求的进程内缓存观察命中率为 0%。每副本分别计数的熔断未能稳定缩短故障长尾，两处均已移出当时的实现。故障注入与本地回归验证了拨号沿用请求截止时间，以及超时后退回原召回的行为。预发探针验证的是故障回退，排序净收益以三题集复验为准。

此评估覆盖记忆检索候选。候选池缺少独立文档检索一路的正确页样本，部分标注未经完整人工校准。逐条判断仅用于弱相关提示可作为独立方案评估，证据见 [E015](../E015-two-stage-rerank-replay/README.md)。
