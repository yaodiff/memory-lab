# E029 统一版与精简版指令的两轮 81 题终验均未过门槛

- 结论：**Does not meet the bar**（两轮都在部分子集显著变好，但各有退步或新增过度断言；主管裁定暂停记忆指令微调，改靠后端检索修复）
- 日期：2026-11-26（统一版第一轮终验为 11-25 深夜，精简子集为 11-26 凌晨）
- Issue：[#93](https://github.com/yaodiff/memory-lab/issues/93)
- 来源：自有场景小样本；65 题检索/作答集加 16 题回源与对照集，外加 24 题外部仓路由复核
- 交接：无（不落指令合并请求；精确补丁留存于内部实验目录备查）

## 假设与做法

[E026](../E026-three-gap-regression/README.md) 和 [E027](../E027-live-recall-contract-recheck/README.md) 里零散验证过几条指令改法：外部仓边界、短句保留原词、无关页不附挂、约 85 字回源核实，以及一组工程交付验收清单。假设把它们合并进正式指令（净增控制在约 200 字内）能同时通过预设硬门槛：目标 34 题相对真召回基线净增至少 2 题且无新增过度断言；非目标 31 题零退步且相对基线正向；锚点题与回源集保持满收益；纯决策题不误查源码；外部仓题全部跳过内部记忆。

第一轮做统一合稿并允许一次精调（r1、r2）。r2 未过门后，第二轮按建议拆掉工程交付清单，只保留约 110 字净增的四处「纯记忆使用」改动，再跑同一套冻结输入。两季都严格复用此前冻结的召回包与基线回执，只运行新指令臂，使用同一模型、同一盲判口径和 10,000 次配对 bootstrap，并对关键进出题做人工并排复核。

## 数据

**第一轮：统一版 r2（净增约 196 字符）**

- 回源/路由子集全部达标：锚点三轮题 3/3 通过、0 过度推断；12 道必回源题 9/12、0/12 过度推断；4 道纯决策题在有无路径提示两种口径下均 0/4 误查文件；外部仓 12 道主集加 2 个变体全部跳过。
- 65 题主集未达标：目标 34 题 27/34，只比真召回基线 26/34 净增 +1（门槛为 ≥+2），且出现 1 例机判过度断言、1 道行为题真实退步；非目标 31 题 22/31，虽比真召回臂 19/31 高 +9.68 个百分点（CI [−3.23, +22.58]，跨零），但有 1 道旧题持续退步。
- 定位到的核心矛盾：在约 200 字上限内同时塞「记忆检索/回源边界」和「通用交付验收清单」产生篇幅竞争，验收模板挤掉了行为题需要的具体回归入口。

**第二轮：精简子集（净增约 110 字符，只留四处记忆规则）**

- 亮点继续扩大：目标检索 18/18 且 0 trap/0 过度断言（修回上一轮的机判过度断言题）；非目标升到 23/31（比真召回臂 +12.90 个百分点，CI [0, +29.03]），并首次清零一道跨空间题的 trap；12 道必回源题完整通过 10/12（系列最高），锚点三轮题 3/3、0 过度推断；纯决策对照两种口径均 0/4 误查、4/4 正确。
- 但五项硬门槛只过一项：目标总计 24/34，低于真召回基线 26/34——行为题从 8/16 退到 6/16（两题退步，CI [−31.25, 0]），即使删掉了交付清单长句，回源指令仍把有限回答篇幅导向「待核实缺口」，挤掉测试方案设计；非目标仍有同一道旧题退步；回源集新增 1/12 机判过度断言（模型对未读到实现的函数名做了语义外推）；外部仓主集 12/12 跳过，但不带仓名的裸产品名变体出现 1 次误触发。
- 两轮之间的差异大多落在单次运行的置信区间内，没有形成稳定、可复现的净收益。

## 结论与是否采用

**两轮终验均不达标，裁定暂停记忆指令的提示词微调，改靠后端检索修复。** 依据是：

1. 同一组规则在不同题组间出现收益与退步的交换，压缩字数只改变退步位置，没有消除交换；
2. 部分失败是提示词的物理天花板——当可见记忆页自信地写着过时目标且没有反证时，任何措辞都无法凭空纠正，只能靠回源工具或更好的检索；
3. 高 ROI、低副作用的杠杆已转移到后端：外部仓守卫与原始查询双路融合（[E026](../E026-three-gap-regression/README.md)）、实体截断与闭环漏抽修复（[E028](../E028-session-memory-v3-retest/README.md)）、大实体页拆短（[E027](../E027-live-recall-contract-recheck/README.md)）。

已验证有效的局部措辞（克制回源段、无关页不附挂）作为后续候选知识保留，但本轮不合并、不发布。

## 没覆盖的

全部是离线固定输入与单一模型的仿真，没有真实多轮 Agent 流量，也没有线上采纳率读数。每臂基本只跑一次（仅锚点题重复三轮），无法把提示词效应与运行间方差完全分开；报告自己也指出两轮差异落在单次 CI 内。裁判存在截断误伤和宽严摆动，已用人工复核修正但不可能逐题重判。这里的「暂停」是当前题集与样本量下的优先级决定，不是证明任何指令改写都无效。
