## 假设与做法

提示每条证据适用的对象、条件和操作，可能减少用错记忆。对 243 题做配对离线重放。两臂共享冻结查询、候选顺序和证据原文，实验臂给可标注页面加范围提示和采纳前核对说明。明确范围优先，标题推断另作标记。修复评分器投影时漏传范围、路由和版本的缺陷，确保裁判拿到作答臂能看到的必要信息。

按题计分。正确要求结论或明确下一步有题内证据并且没有过度断言。误采纳要求答复实际使用了可见但不适用、过时或冲突的信息。置信区间来自 10,000 次按题配对 bootstrap。

## 结论与边界

结果方向有利，正确率区间跨零，误采纳的绝对样本也很小。暂不默认开启。两臂回放的检索材料是固定的，多轮 Agent 是否会改查词、换阅读顺序或少开某一页仍需实测。这个实验只支持修复后评分契约下的固定输入比较。
