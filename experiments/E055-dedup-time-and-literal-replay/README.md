- 结论：**Does not work**
- 日期：2026-11-29
- Issue：[#101](https://github.com/yaodiff/memory-lab/issues/101)
- 方法：复测调研的第 3、5、6 项，分别为用来源及版本族收回重复槽、按明示时间点或版本选证据、给技术标识补一个字面候选槽。冻结融合排序与候选，另用已存实返做敏感性对照。
