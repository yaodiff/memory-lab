# 教训：平台操作先读手册

来源：内部小样本的离线检索回放和真实 Agent 的只读对照。

- **Does not work**。在搜索结果末尾推荐平台手册，试过正则、语义匹配、只看平台名。正则在自己出的题上全对，独立泛化题里，有手册可指的题精确指对约一半，业务题约一半误触发。语义版本约四成精确指对，业务误触发仍约四分之一。只看平台名约三成精确指对，独立泛化样本里的业务题全部误触发。精确命中要求推荐集合等于标注集合。业务题只要出现手册推荐就算误触发。自己出的题适合做回归，泛化需要独立题。
- **Works**。在 Skill 中让 Agent 先打开适用的官方操作手册，手册无覆盖或具体症状仍待解释时再查记忆。真实 Agent 的内部小样本里，平台题严格手册优先率从约 25% 到约 81%，记忆调用率从 100% 到约 19%。初版最终读到正确手册的比例也从 100% 降到约 81%。修订为明确要求打开手册后，平台回归中优先率和最终覆盖均为 100%。业务题在初版对照中先搜记忆的比例两组都约七成。
- **Inconclusive**。修订后的回归只覆盖平台题，实际安装环境的工具发现和带症状时的补搜待验。手册优先的 Skill 仍是草稿。
